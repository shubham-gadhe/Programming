## Compile and Run

Compile a program using GCC:

```bash
gcc PP_001.c -o Myexe
```

Run the executable:

**Windows:**
```bash
Myexe.exe
```

**Linux / macOS:**
```bash
./Myexe
```

Replace `PP_001.c` with the filename of the program you want to execute.
